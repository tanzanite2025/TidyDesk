## ✨ 新功能详解

### 1. 系统托盘 ⭐⭐⭐⭐⭐

**最重要的更新！** 应用现在会常驻在系统托盘中。

#### 功能特性

- 📌 **托盘图标**: 应用图标显示在任务栏右下角
- 🖱️ **右键菜单**: 
  - 显示/隐藏窗口
  - 开关开机自启
  - 查看内存使用
  - 退出应用
- 🖱️ **双击图标**: 快速切换窗口显示/隐藏
- 📊 **实时信息**: 托盘菜单显示当前内存使用情况

#### 使用方法

```
1. 启动 TidyDesk
2. 关闭窗口 → 应用隐藏到托盘（不退出）
3. 右键托盘图标 → 显示菜单
4. 双击托盘图标 → 重新显示窗口
5. 只能从托盘菜单选择"退出"才真正退出
```

### 2. 防止误退出 ⭐⭐⭐⭐⭐

**再也不用担心误关闭！**

#### 改进前
```
关闭窗口 → 应用退出 → 需要重新启动 ❌
```

#### 改进后
```
关闭窗口 → 隐藏到托盘 → 应用继续运行 ✅
```

#### 退出方式
- ✅ 托盘菜单 → 退出 TidyDesk
- ❌ 关闭窗口（只是隐藏）
- ❌ Alt+F4（只是隐藏）

### 3. 单实例锁 ⭐⭐⭐⭐

**防止重复启动，避免资源浪费。**

#### 行为
- 第一次启动：正常运行
- 第二次启动：自动聚焦到第一个实例
- 任务管理器：只有一个 TidyDesk.exe 进程

#### 优势
- 避免数据冲突
- 节省系统资源
- 更好的用户体验

### 4. 开机自启动 ⭐⭐⭐⭐

**开机即可用，无需手动启动。**

#### 首次启动
- 延迟 5 秒后弹出询问对话框
- 用户可选择"是"或"否"
- 不会强制开启

#### 后续管理
- 托盘菜单 → 开机自启动（勾选框）
- 随时开关，立即生效

#### 启动行为
- 系统启动后自动运行
- 窗口正常显示（不隐藏）
- 所有功能立即可用

### 5. 内存监控 ⭐⭐⭐

**长期运行也稳定，自动管理内存。**

#### 监控机制
- ⏰ 每 10 分钟自动检查
- 📊 实时记录内存使用
- 🧹 超过 500MB 自动触发 GC
- 🗑️ 每小时清理缓存

#### 内存显示
- 托盘菜单显示当前内存占用
- 每 30 秒自动更新
- 格式：`内存使用: XXmb`

#### 预期效果
- 正常使用：100-150MB
- 长时间运行：不超过 200MB
- 内存泄漏：自动检测和清理

### 6. 电源管理 ⭐⭐⭐

**智能响应系统事件，无缝体验。**

#### 支持的事件

| 事件 | 应用行为 |
|------|----------|
| 系统休眠 | 暂停资源密集操作 |
| 系统恢复 | 自动恢复运行 |
| 系统关机 | 保存状态后优雅退出 |

#### 优势
- 节省电量
- 避免数据丢失
- 无缝恢复

## 🔧 技术实现

### 架构改进

```
electron/
├── main.cjs          # 主进程（集成常驻机制）
├── resident.js       # 常驻机制模块（新增）
├── config.js         # 配置文件（新增 RESIDENT 配置）
└── preload.cjs       # 预加载脚本
```

### 核心代码

```javascript
// 系统托盘
const tray = new Tray('icon.ico');
tray.setContextMenu(menu);

// 防止退出
app.on('window-all-closed', () => {
  // 不调用 app.quit()
});

// 单实例锁
const gotTheLock = app.requestSingleInstanceLock();
if (!gotTheLock) app.quit();

// 开机自启
app.setLoginItemSettings({
  openAtLogin: true
});

// 内存监控
setInterval(() => {
  const memMB = process.memoryUsage().heapUsed / 1024 / 1024;
  if (memMB > 500 && global.gc) global.gc();
}, 10 * 60 * 1000);
```

## ⚠️ 注意事项

### 托盘图标

- 需要 `build/tray-icon.ico` 文件（16x16 像素）
- 如果没有，会尝试使用 `build/icon.ico`
- 如果都没有，托盘功能可能无法正常工作

### 开机自启

- 首次启动会询问用户
- 不会强制开启
- 可随时从托盘菜单开关

### 退出方式

- ⚠️ 关闭窗口不会退出应用
- ✅ 必须从托盘菜单选择"退出"
- ✅ 或者使用任务管理器结束进程

### 内存监控

- 需要启动时加 `--expose-gc` 参数才能手动触发 GC
- 如果没有，内存监控仍然工作，但无法手动 GC
- 正常使用不影响
