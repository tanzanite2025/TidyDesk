# TidyDesk v3.2.1 发布说明

**发布日期**: 2026-05-24  
**版本类型**: 补丁版本（Patch）  
**重点**: 优化开机自启询问时机

---

## 📋 版本概述

v3.2.1 是 v3.2.0 的优化版本，主要改进了开机自启询问的用户体验，让弹窗时机更加智能和友好。

---

## ✨ 主要改进

### 🎯 智能询问时机

#### 改进前（v3.2.0）
```
启动应用 → 延迟 5 秒 → 弹出询问对话框
```

**问题**:
- ❌ 固定 5 秒可能不够，用户还在熟悉界面
- ❌ 可能在用户操作时突然弹出，打断操作
- ❌ 时机不够智能

#### 改进后（v3.2.1）
```
策略 1: 启动应用 → 等待 30 秒 → 如果用户未交互 → 弹出询问
策略 2: 启动应用 → 用户首次使用功能 → 延迟 2 秒 → 弹出询问
```

**优势**:
- ✅ 给用户更多时间熟悉界面
- ✅ 在用户完成操作后询问，不打断
- ✅ 更智能的时机判断

### 📝 对话框改进

#### 新增"稍后提醒"选项

**v3.2.0**:
```
按钮: [是] [否]
```

**v3.2.1**:
```
按钮: [是] [否] [稍后提醒]
```

**行为**:
- **是**: 启用开机自启，不再询问
- **否**: 不启用，不再询问
- **稍后提醒**: 本次不决定，下次启动继续询问

#### 更详细的说明

**v3.2.0**:
```
是否设置开机自动启动？
开机自启可以让 TidyDesk 始终为您服务，随时整理桌面。
```

**v3.2.1**:
```
是否设置开机自动启动？
开机自启可以让 TidyDesk 始终为您服务，随时整理桌面。

您可以随时从系统托盘菜单中更改此设置。
```

### 🔍 询问记录机制

使用标记文件 `.auto-start-asked` 记录是否已询问：

- **已询问且选择"是"或"否"**: 创建标记文件，不再询问
- **选择"稍后提醒"**: 不创建标记文件，下次启动继续询问
- **标记文件位置**: `%APPDATA%\TidyDesk\.auto-start-asked`

## 🔧 技术实现

### 智能时机判断

```javascript
// 策略 1: 30 秒超时
const timeoutId = setTimeout(() => {
  if (!hasUserInteracted) {
    showAutoStartDialog();
  }
}, 30000);

// 策略 2: 用户交互触发
ipcMain.once('file-dropped', () => {
  hasUserInteracted = true;
  clearTimeout(timeoutId);
  setTimeout(() => showAutoStartDialog(), 2000);
});
```

### 用户交互事件

监听以下事件作为"首次交互"：
- `file-dropped`: 用户拖拽文件到抽屉
- `drawer-opened`: 用户打开抽屉
- `user-first-interaction`: 其他首次交互

### 标记文件

```javascript
const askedFlagFile = path.join(app.getPath('userData'), '.auto-start-asked');

// 检查是否已询问
if (fs.existsSync(askedFlagFile)) {
  return; // 已询问过，跳过
}

// 用户选择"是"或"否"后创建标记
fs.writeFileSync(askedFlagFile, new Date().toISOString());
```

```typescript
interface TidyDeskAPI {

interface Window {
  tidyDesk: TidyDeskAPI;
```

## 📝 使用说明

### 首次启动体验

**场景 1: 立即使用功能**
```
1. 启动 TidyDesk
2. 拖拽文件到抽屉（首次交互）
3. 2 秒后弹出询问对话框
4. 选择"是"/"否"/"稍后提醒"
```

**场景 2: 先观察界面**
```
1. 启动 TidyDesk
2. 观察界面、了解功能
3. 30 秒后弹出询问对话框
4. 选择"是"/"否"/"稍后提醒"
```

### 选择"稍后提醒"

如果选择"稍后提醒"：
- 本次不会再询问
- 下次启动应用时继续询问
- 可以多次选择"稍后提醒"
- 直到选择"是"或"否"为止

### 修改设置

随时可以从托盘菜单修改：
1. 右键系统托盘的 TidyDesk 图标
2. 勾选/取消勾选"开机自启动"
3. 立即生效
