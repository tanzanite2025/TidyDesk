## 技术架构

### 存储结构
```
AppData\Roaming\TidyDesk\
├── drawers\          # 抽屉（快捷方式）
│   └── 收纳抽屉\
│       └── 文件.lnk
└── storage\          # 文件存储（实际文件）
    └── {timestamp}-{random}\
        └── 文件.ext
```

### 工作流程
```
拖入文件 → 移动到 storage → 创建快捷方式 → 桌面文件消失
还原文件 → 移回桌面 → 删除快捷方式 → 清理存储目录
```

## 用户指南

### 基本使用
1. **整理桌面**: 拖动文件到抽屉，桌面立即整洁
2. **访问文件**: 双击抽屉中的文件，正常打开
3. **还原文件**: 鼠标悬停 → 点击还原按钮（↩️）→ 确认

### 注意事项
- ⚠️ 从桌面拖入 = 移动（桌面文件消失）
- ⚠️ 从其他位置拖入 = 复制（原文件保留）
- ⚠️ 还原操作会将文件移回桌面
- ⚠️ 删除快捷方式不会删除存储中的文件

### 常见问题

**Q: 文件存储在哪里？**
A: `C:\Users\{用户}\AppData\Roaming\TidyDesk\storage\`

**Q: 桌面文件去哪了？**
A: 移动到 TidyDesk 的隐藏存储中，通过抽屉访问。

**Q: 如何找回文件？**
A: 点击文件上的还原按钮（↩️），文件会回到桌面。

**Q: 删除快捷方式会删除文件吗？**
A: 不会。删除快捷方式只删除抽屉入口，文件保留在存储中。

**Q: 旧版本的快捷方式还能用吗？**
A: 可以。旧版本快捷方式继续有效，但不能使用还原功能。
