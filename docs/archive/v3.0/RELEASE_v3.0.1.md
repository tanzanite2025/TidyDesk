## TidyDesk v3.0.1 - Bug 修复版本

这是一个 bug 修复版本，解决了 v3.0.0 中发现的几个用户体验问题。

### 🐛 修复的问题

#### 1. 启动状态一致性
- **问题**: 应用启动时手柄在展开位置，但抽屉没有显示
- **修复**: 确保启动时手柄和抽屉都在正确的收起位置
- **影响**: 提升启动体验，避免视觉错位

#### 2. 动画同步问题
- **问题**: 展开/收起时手柄先到位，抽屉后到位，动画不协调
- **修复**: 统一所有动画时长为 250ms，手柄和抽屉完全同步
- **影响**: 动画更加流畅，视觉效果更好

#### 3. 抽屉重命名失败
- **问题**: 右键重命名抽屉时报错 "Rename is only allowed for drawer entries"
- **修复**: 支持重命名抽屉本身和抽屉内的文件
- **影响**: 重命名功能完全可用

### 🔧 技术改进

- 优化窗口初始化流程
- 统一动画时长（250ms）
- 改进 IPC 处理器逻辑
- 添加更多安全检查
