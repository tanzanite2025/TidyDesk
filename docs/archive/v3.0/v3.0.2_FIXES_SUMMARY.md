# TidyDesk v3.0.2 修复总结

## 版本信息
- **版本号**: v3.0.2

- **修复数量**: 2 个问题

## 修复列表

### 1. ✅ 任务栏图标问题
**问题**: 手柄窗口出现在 Windows 任务栏，应该只在系统托盘显示

**修复**:
- 文件: `electron/main.cjs`
- 修改: `skipTaskbar: false` → `skipTaskbar: true`
- 效果: 手柄窗口不再出现在任务栏，只在系统托盘显示

**详细文档**: `TASKBAR_AND_FILENAME_FIXES.md`

---

### 2. ✅ 文件图标显示问题
**问题**: 桌面文件的自定义图标在抽屉中变成通用分类图标

**修复**:
- 文件: `electron/main.cjs`, `src/types/file.ts`, `src/App.tsx`
- 实现: 使用 `app.getFileIcon()` API 获取 Windows 系统真实图标
- 效果: 抽屉中显示与桌面一致的文件图标

**详细文档**: `ICON_DISPLAY_FIX.md`

---

## 技术实现

### 任务栏修复
```javascript
// electron/main.cjs - createHandleWindow()
skipTaskbar: true  // 不在任务栏显示
```

### 图标显示修复
```javascript
// electron/main.cjs - read-desktop-files
if (isValid && targetPath) {
  const icon = await app.getFileIcon(targetPath, { size: 'normal' });
  iconPath = icon.toDataURL();
}

// src/App.tsx - FileTile
{file.icon ? (
  <img src={file.icon} alt={file.name} className="h-8 w-8" />
) : (
  categoryIcon(file.category)
)}
```

## 性能影响
- 图标获取是异步操作，不阻塞 UI
- Base64 图标数据会增加少量内存使用（每个图标约 2-5KB）
- 图标获取失败会自动降级，不影响功能
