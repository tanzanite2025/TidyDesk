# TidyDesk 快速退出指南

## 🚪 如何退出 TidyDesk

### ⚡ 方法 1: 快捷键（最快）

按键盘上的：
```
Ctrl + Alt + Q
```

✅ **推荐使用** - 最快速、最可靠的退出方式

---

### 🖱️ 方法 2: 托盘菜单

1. 找到任务栏右下角的托盘图标区域（时钟旁边）
2. 如果图标被隐藏，点击 **^** 展开隐藏图标
3. 找到 TidyDesk 图标（蓝色方块）
4. **右键点击**图标
5. 选择 **"⚠️ 退出 TidyDesk (Ctrl+Alt+Q)"**

---

### 🔧 方法 3: 任务管理器（备用）

如果上述方法都不行：

1. 按 `Ctrl + Shift + Esc` 打开任务管理器
2. 在"进程"标签页找到 **TidyDesk**
3. 右键点击 → 选择 **"结束任务"**

或使用命令行：
```bash
taskkill /F /IM TidyDesk.exe
```

---

## ⚠️ 重要提示

### 关闭窗口 ≠ 退出应用

- ❌ 点击窗口的 X 按钮 → **只是隐藏窗口**
- ✅ 使用上述方法 → **完全退出应用**

### 为什么这样设计？

TidyDesk 是一个**常驻应用**，设计为在后台持续运行：
- 📌 随时可以快速打开
- 🔄 持续监控桌面文件
- ⚡ 提供快捷操作

---

## 🔍 如何确认应用已退出

### 检查托盘图标
- 托盘区域不再显示 TidyDesk 图标

### 检查任务管理器
1. 按 `Ctrl + Shift + Esc`
2. 在"进程"中搜索 "TidyDesk"
3. 如果找不到，说明已完全退出

---

## 💡 常见问题

### Q: 我找不到托盘图标怎么办？
**A:** 使用快捷键 `Ctrl+Alt+Q` 直接退出

### Q: 为什么有多个 TidyDesk 在运行？
**A:** 
1. 使用任务管理器结束所有 TidyDesk 进程
2. 重新启动应用
3. 应用有单实例保护，正常情况下只会运行一个

### Q: 快捷键不起作用怎么办？
**A:** 
1. 确认没有其他应用占用该快捷键
2. 使用托盘菜单退出
3. 使用任务管理器强制结束

### Q: 我想让应用开机自启动吗？
**A:** 
1. 右键托盘图标
2. 勾选"开机自启动"选项
