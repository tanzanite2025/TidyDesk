# TidyDesk 快速开始指南 🚀

> 5 分钟快速上手 TidyDesk

---

## 📥 第一步：安装

### 下载安装程序

1. 访问 [GitHub Releases](https://github.com/your-github-username/TidyDesk/releases)
2. 下载最新版本的 `TidyDesk-Setup.exe`
3. 双击运行安装程序

### 安装选项

- **安装位置**: 可以自定义安装路径
- **桌面快捷方式**: 建议勾选
- **开始菜单**: 建议勾选

### 首次启动

安装完成后，TidyDesk 会自动启动。你会看到：
- 屏幕右侧的**手柄**（可以点击展开抽屉）
- 点击手柄后，抽屉会从右侧滑出

---

## 🗂️ 第二步：创建第一个抽屉

### 创建抽屉

1. 点击屏幕右侧的**手柄**展开抽屉
2. 点击左上角的 **"+"** 按钮
3. 输入抽屉名称，例如：
   - "工作文件"
   - "个人照片"
   - "临时文件"
4. 点击 **"创建"** 按钮

### 抽屉卡片

创建后，你会看到一个**卡片**，显示：
- 📁 抽屉名称
- 📊 文件数量（初始为 0）
- ⚠️ 失效快捷方式数量（如果有）

---

## 🖱️ 第三步：整理桌面文件

### 拖拽文件到抽屉

1. 从桌面选择一个或多个文件
2. 拖拽到抽屉卡片上
3. 松开鼠标
4. 文件会自动添加到抽屉

### 重要说明

⚠️ **TidyDesk 不会移动你的原文件！**

- 原文件保持在原位置
- 抽屉中只是快捷方式
- 删除快捷方式不会删除原文件
- 完全安全，可以放心使用

### 打开文件

- 点击抽屉中的文件即可打开
- 就像点击桌面上的文件一样

---

## 🔍 第四步：验证和修复

### 自动验证

TidyDesk 会自动检测失效的快捷方式：
- 启动时自动验证
- 每 30 分钟自动验证
- 实时监控文件变化

### 识别失效快捷方式

失效的快捷方式会显示：
- 🔴 **红色边框**
- ⚠️ **警告图标**
- 📊 **透明度降低**（60%）

### 修复失效快捷方式

#### 方法 1: 单个修复
1. 找到失效的快捷方式（红色边框）
2. 点击右侧的 **🔧 修复按钮**
3. TidyDesk 会自动搜索文件
4. 如果找到，会自动修复

#### 方法 2: 批量清理
1. 点击顶部的 **🧹 清理失效快捷方式** 按钮
2. 确认删除
3. 所有失效快捷方式会被删除

#### 方法 3: 手动验证
1. 点击顶部的 **🔍 验证** 按钮
2. TidyDesk 会验证所有快捷方式
3. 尝试自动修复
4. 显示验证结果

---

## ⚙️ 第五步：检查更新

### 打开设置面板

1. 点击右上角的 **⚙️ 设置按钮**
2. 设置面板会弹出

### 查看应用信息

设置面板显示：
- 📱 应用名称: TidyDesk
- 📌 当前版本: v3.0.0
- 🔧 运行模式: 生产模式

### 检查更新

1. 点击 **"检查更新"** 按钮
2. 等待检查结果

#### 如果有新版本
1. 显示 **"发现新版本: vX.X.X"**
2. 显示发布说明
3. 点击 **"下载更新"** 按钮
4. 等待下载完成（显示进度条）
5. 点击 **"安装并重启"** 按钮
6. 应用会自动重启并安装更新

#### 如果已是最新版本
- 显示 **"✅ 已是最新版本"**

## 🎯 常用操作

### 管理抽屉

#### 重命名抽屉
1. 右键点击抽屉卡片
2. 选择 **"重命名"**
3. 输入新名称
4. 点击确认

#### 删除抽屉
1. 右键点击抽屉卡片
2. 选择 **"删除"**
3. 确认删除
4. 抽屉及其中的快捷方式会被删除

⚠️ **注意**: 删除抽屉不会删除原文件

### 管理文件

#### 打开文件
- 点击文件即可打开

#### 删除快捷方式
1. 右键点击文件
2. 选择 **"删除"**
3. 确认删除

⚠️ **注意**: 删除快捷方式不会删除原文件

### 展开/收起抽屉

- 点击屏幕右侧的**手柄**
- 或者点击抽屉内的 **"收起"** 按钮

## ❓ 常见问题

### Q1: 原文件会被移动吗？

**不会！** TidyDesk 只创建快捷方式，原文件保持在原位置。

### Q2: 删除快捷方式会删除原文件吗？

**不会！** 删除快捷方式只是删除链接，原文件完全不受影响。

### Q3: 为什么有些快捷方式显示红色边框？

这表示目标文件已被移动或删除。你可以：
- 点击 🔧 按钮尝试修复
- 或者删除这个快捷方式

### Q4: 如何找回移动的文件？

TidyDesk 会自动在这些位置搜索：
- 桌面
- 文档
- 下载
- 图片
- 视频

如果文件在这些位置，点击 🔧 按钮即可自动修复。

### Q5: 抽屉数据存储在哪里？

抽屉数据存储在：
```
C:\Users\你的用户名\AppData\Roaming\TidyDesk\drawers\
```

### Q6: 如何卸载 TidyDesk？

1. 打开 Windows 设置
2. 选择 "应用" → "已安装的应用"
3. 找到 "TidyDesk"
4. 点击 "卸载"

⚠️ **注意**: 卸载后，抽屉数据会保留，但快捷方式会失效。

### Q7: 更新后数据会丢失吗？

**不会！** 更新只会替换程序文件，你的抽屉和快捷方式完全不受影响。
