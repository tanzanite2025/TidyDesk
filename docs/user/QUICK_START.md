# TidyDesk 快速开始

这份文档只保留当前 Tauri 版本的日常使用入口。

## 基本流程

1. 启动 TidyDesk 后，通过屏幕边缘把手打开抽屉。
2. 将桌面文件拖入抽屉，TidyDesk 会在抽屉内创建入口；来自桌面的普通文件会移动到托管 storage，抽屉入口指向该托管文件。
3. 需要恢复时，在抽屉内选择恢复到桌面；恢复会移动回桌面并移除对应快捷入口。
4. 应用选择器可把已安装应用快捷方式加入抽屉。
5. 截图贴纸流程：打开截图遮罩，框选区域后生成桌面贴纸；最近一次截图也可以通过设置里的贴图快捷键贴出。

## 设置与数据

- 常驻、托盘、自动启动等开关在设置面板中管理。
- 贴图快捷键可在设置面板中修改；保存时会做格式和注册冲突检测。
- 本地数据写入应用数据目录，主要包括 `drawers/`、`storage/`、`todos/`、`stickers/` 和快速便签状态。
