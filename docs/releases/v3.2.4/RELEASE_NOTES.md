# TidyDesk v3.2.4 - Hotfix Release

## 🐛 紧急修复

本版本修复了 v3.2.3 中的严重启动问题。

### 修复的问题

1. **应用无法启动**
   - **问题**：打包后的应用启动时出现 JavaScript 错误
   - **原因1**：`package.json` 中的 `"type": "module"` 配置导致所有 .js 文件被当作 ES Module，但 Electron 主进程代码使用 CommonJS 格式
   - **原因2**：`resident.cjs` 文件中存在语法错误（重复的 catch 块）
   - **解决**：移除 `"type": "module"` 配置，修复语法错误

### 影响范围

- ✅ 修复了应用打包后无法启动的致命问题
- ✅ 不影响任何功能特性
- ✅ 保留了 v3.2.3 的所有性能优化和新功能

## ⚠️ 重要提示

**v3.2.3 版本存在严重的启动问题，建议所有用户立即升级到 v3.2.4。**
