## 🚀 核心特性

### 增量更新 - 实时检测应用变化

v3.4.0 引入了基于 Windows 注册表监听的增量更新机制，实现了应用安装/卸载的实时检测和快速更新。

#### 工作原理

```
应用安装/卸载
  ↓
注册表变化
  ↓
< 5 秒检测到 ✅
  ↓
只更新该应用（< 1s）✅
  ↓
立即显示在列表中 ✅
```

#### 关键特性

- ✅ **实时检测** - < 5 秒检测到应用变化
- ✅ **增量更新** - 只更新变化的应用，< 1 秒完成
- ✅ **自动同步** - 无需手动刷新
- ✅ **智能兜底** - 24 小时全量扫描确保准确性

## ✨ 新增功能

### 1. 注册表监听

- 监听 Windows 注册表的三个关键位置
  - 64 位应用注册表
  - 32 位应用注册表
  - 用户级应用注册表
- 每 5 秒检查一次变化
- 事件驱动架构，高效可靠

### 2. 增量更新

- **安装检测**: 应用安装后 < 5 秒自动添加到列表
- **卸载检测**: 应用卸载后 < 5 秒自动从列表移除
- **智能查找**: 自动在开始菜单中查找快捷方式
- **快速更新**: 只更新变化的应用，< 1 秒完成

### 3. 智能兜底

- 定期全量扫描（24 小时）
- 确保缓存准确性
- 防止遗漏和错误

## 🔧 技术改进

### 新增服务

**注册表监听服务** (`registry-watcher.cjs`)
- 200+ 行代码
- 事件驱动架构
- 自动错误恢复
- 优雅降级

### 增强功能

**应用服务** (`apps.cjs`)
- `updateSingleApp()` - 增量添加/更新
- `removeSingleApp()` - 增量移除
- `findAppShortcut()` - 智能查找
- 失败自动回退到全量扫描

### 主进程优化

**启动流程优化**
```
0s    - 应用启动
3s    - 检查更新
10s   - 后台扫描应用
15s   - 启动注册表监听 ✅
```

**定期任务调整**
- 全量扫描间隔：1 小时 → 24 小时
- 增量更新：实时（< 5 秒）

## ⚠️ 注意事项

### 1. Windows 专用

- 注册表监听仅支持 Windows
- 非 Windows 系统自动禁用此功能
- 回退到定期扫描（24 小时）

### 2. 检测延迟

- 最多 5 秒延迟
- 平衡实时性和性能
- 可以接受的延迟

### 3. 某些应用可能遗漏

- 绿色软件（不写注册表）
- 便携版应用
- 手动安装的应用

**解决方案**:
- 定期全量扫描兜底（24 小时）
- 用户可以手动刷新

### 4. 资源消耗

- 内存增加约 5 MB
- CPU 使用 < 1%
- 可以忽略不计

## 🐛 已知问题

### 1. 检测延迟

**现象**: 最多 5 秒延迟

**原因**: 每 5 秒检查一次注册表

**影响**: 轻微，可以接受

**解决**: 无需解决，设计如此

### 2. 绿色软件检测

**现象**: 绿色软件可能不会被检测到

**原因**: 绿色软件不写注册表

**影响**: 轻微，少数应用

**解决**: 定期全量扫描兜底
